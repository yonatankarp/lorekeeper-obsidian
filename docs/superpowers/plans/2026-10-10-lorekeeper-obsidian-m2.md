# Lorekeeper for Obsidian, M2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Updates that reach a vault already full of notes, Lorekeeper's status marks and attitude colours, an Obsidian Git backup path, and D&D Beyond import with optional pasted-cookie sign-in.

**Architecture:** As in M1: pure CommonJS modules in `_lorekeeper/lib/` (unit-tested with `node --test`, loaded in Obsidian by `load.js`), thin QuickAdd scripts in `_lorekeeper/scripts/`, pinned third-party plugins committed under `.obsidian/plugins/`, the theme generated by `scripts/build-theme.js`. Obsidian-specific glue that can be tested with a fake app lives in `lib/` too and takes `app`/`requestUrl` as arguments.

**Tech Stack:** Obsidian 1.13+, QuickAdd 2.32.1, Templater 2.25.1, Dataview 0.5.70, Custom Selectors 1.1.0, Supercharged Links 0.14.0 (new), Obsidian Git 2.41.1 (new, off by default). Node 22 for tests. No npm dependencies.

**Spec:** `docs/superpowers/specs/2026-10-10-lorekeeper-obsidian-m2-design.md` (M1's spec `2026-10-10-lorekeeper-obsidian-design.md` still binds).

**USER CHECKPOINT steps** need a person (Obsidian, a browser, or publishing to GitHub). The executor finishes the task's code and tests, commits, and collects the checkpoints into one list for the user at the end, except Task 10's publishing gate, which must stop and get the user's explicit go-ahead before any push.

- The D&D Beyond cookie lives only in `app.secretStorage` under the id `lorekeeper-dndbeyond`, never in a file, a log or a Notice.
- UI copy: plain words, **bold** labels in docs, both `⌘` and `Ctrl`, no em dashes. Commit subjects `kind(Area): what changed` with your harness trailer.

## Review Focus

1. **An update must never clobber a player's edit.** An edited shared file is kept and listed; a file the player deleted that the release still ships is not re-created if it was shared, is re-created if managed (Task 1 tests `keeps an edited shared file`, `re-creates a deleted managed file`, `does not re-create a deleted shared file`).
2. **A half-finished update is safe to rerun.** Downloads are verified against the manifest hash before any write; `installed.json` is written last (Task 2 test `writes installed.json last and skips files that fail their hash`).
3. **Paths with spaces in downloads** (`Cheat Sheet.md`) must be URL-encoded per segment (Task 2 test `rawUrl encodes each path segment`).
4. **A D&D Beyond reply with missing or odd fields** must give empty values, never a crash (Task 6 test `reads a reply defensively`, ported from Lorekeeper's `character_reply_is_read_defensively`).
5. **The cookie never reaches a file.** Sign-in stores it in secret storage only, strips a pasted `CobaltSession=` prefix, and refuses when secret storage is missing (Task 8 test `signIn stores only in secret storage`).

```js
// Updates: which files a release owns (managed), which the player may have edited (shared), and the plan that moves a
// vault to a new release without touching an edit. The Update command (scripts/update.js) does the downloads.

const MANAGED = [
  /^_lorekeeper\/(?!installed\.json$).+/,
  /^\.obsidian\/themes\/.+/,
  /^\.obsidian\/plugins\/[^/]+\/(main\.js|manifest\.json|styles\.css|LICENSE)$/,
  /^CREDITS\.md$/,
  /^docs\/(CAPTURE|BACKUP|DNDBEYOND)\.md$/,
];
const SHARED = [
  /^Templates\/[^/]+\.md$/,
  /^\.obsidian\/plugins\/[^/]+\/data\.json$/,
  /^\.obsidian\/(hotkeys|app|appearance|core-plugins|community-plugins|graph|bookmarks)\.json$/,
  /^Home\.md$/,
  /^Cheat Sheet\.md$/,
];
const MERGED = [".obsidian/community-plugins.json", ".obsidian/plugins/quickadd/data.json"];

function categorize(path) {
  if (path.endsWith("/.gitkeep")) return null;
  if (MANAGED.some((r) => r.test(path))) return "managed";
  if (SHARED.some((r) => r.test(path))) return "shared";
  return null;
}

function planUpdate({ installed, current, release }) {
  const plan = { add: [], replace: [], kept: [], remove: [], merge: [] };
  const was = installed?.files ?? {};
  const edited = (path) => path in current && path in was && current[path] !== was[path];
  for (const path of Object.keys(release.files).sort()) {
    const { sha256, kind } = release.files[path];
    if (MERGED.includes(path)) plan.merge.push(path);
    else if (!(path in current)) {
      if (kind === "managed" || !(path in was)) plan.add.push(path);
      else plan.kept.push(path); // a shared file the player deleted stays deleted
    } else if (current[path] === sha256) continue;
    else if (kind === "managed" || !edited(path)) plan.replace.push(path);
    else plan.kept.push(path);
  }
  for (const path of Object.keys(was).sort()) {
    if (path in release.files || !(path in current)) continue;
    if (categorize(path) === "managed" || !edited(path)) plan.remove.push(path);
    else plan.kept.push(path);
  }
  return plan;
}

function mergeEnabledPlugins(current, installedPlugins, releasePlugins) {
  const added = releasePlugins.filter((id) => !installedPlugins.includes(id) && !current.includes(id));
  return [...current, ...added];
}

function mergeQuickAdd(current, release) {
  const theirs = new Map(release.choices.map((c) => [c.id, c]));
  const choices = current.choices.map((c) => (c.id.startsWith("lk-") && theirs.has(c.id) ? theirs.get(c.id) : c));
  for (const c of release.choices) if (!choices.some((x) => x.id === c.id)) choices.push(c);
  return { ...current, choices, migrations: { ...current.migrations, ...release.migrations } };
}

async function sha256Hex(text, subtle) {
  const bytes = new TextEncoder().encode(text);
  const digest = await subtle.digest("SHA-256", bytes);
  return [...new Uint8Array(digest)].map((b) => b.toString(16).padStart(2, "0")).join("");
}

const rawUrl = (repo, tag, path) =>
  `https://raw.githubusercontent.com/${repo}/${tag}/${path.split("/").map(encodeURIComponent).join("/")}`;

module.exports = { MERGED, categorize, planUpdate, mergeEnabledPlugins, mergeQuickAdd, sha256Hex, rawUrl };
```

- [ ] **Step 7: Write `scripts/make-manifest.js`**

```js
// Writes lorekeeper.json: every file a release ships (lib/update.js categorize), with its SHA-256, plus the plugins it
// turns on. --ref <commit> --version <v> --out <file> builds one for another commit (the v0.1.0 baseline); --check fails
// when lorekeeper.json is stale.
const fs = require("node:fs");
const path = require("node:path");
const { execFileSync } = require("node:child_process");
const { createHash } = require("node:crypto");
const { categorize } = require("../_lorekeeper/lib/update.js");

const ROOT = path.join(__dirname, "..");
const git = (...args) => execFileSync("git", args, { cwd: ROOT, maxBuffer: 1 << 28 });

function buildManifest({ version, files }) {
  const out = { version, plugins: [], files: {} };
  for (const { path: p, text } of files) {
    const kind = categorize(p);
    if (!kind) continue;
    out.files[p] = { sha256: createHash("sha256").update(text).digest("hex"), kind };
    if (p === ".obsidian/community-plugins.json") out.plugins = JSON.parse(text.toString());
  }
  out.files = Object.fromEntries(Object.entries(out.files).sort(([a], [b]) => (a < b ? -1 : 1)));
  return out;
}

function filesAt(ref) {
  const list = ref ? git("ls-tree", "-r", "--name-only", ref) : git("ls-files");
  return list.toString().split("\n").filter(Boolean).filter((p) => categorize(p))
    .map((p) => ({ path: p, text: ref ? git("show", `${ref}:${p}`) : fs.readFileSync(path.join(ROOT, p)) }));
}

module.exports = { buildManifest };

if (require.main === module) {
  const arg = (name) => { const i = process.argv.indexOf(name); return i === -1 ? null : process.argv[i + 1]; };
  const ref = arg("--ref");
  const version = arg("--version") ?? require("../package.json").version;
  const json = JSON.stringify(buildManifest({ version, files: filesAt(ref) }), null, 2) + "\n";
  const out = arg("--out") ?? path.join(ROOT, "lorekeeper.json");
  if (process.argv.includes("--check")) {
    if (!fs.existsSync(out) || fs.readFileSync(out, "utf8") !== json) {
      console.error("lorekeeper.json is out of date: run npm run make:manifest");
      process.exit(1);
    }
  } else fs.writeFileSync(out, json);
}
```

Returns `{ latest: true }` when `installed.version === release.version`.
  - `async apply({ adapter, request, subtle, update, tag, release, installed, plan }): { written: string[], failed: string[], reload: boolean }` — downloads `add` and `replace` files, verifies each against its manifest hash (a mismatch goes to `failed`, nothing written for it), writes them with `adapter.write` (creating folders with `adapter.mkdir`), removes `remove` with `adapter.remove`, merges the `merge` files, then writes `_lorekeeper/installed.json` (`{ version, plugins, files }` with the hashes of everything now on disk that the release ships) only when `failed` is empty. `reload` is true when any written or removed path is under `.obsidian/plugins/` or `.obsidian/themes/`.
  - `request` has the shape of Obsidian's `requestUrl`: `({ url, method?, headers?, throw? }) => Promise<{ status, json, text, arrayBuffer }>`.

```js
// The Update command's work, with Obsidian's pieces passed in (adapter, requestUrl, crypto.subtle, lib/update.js) so it
// can be tested with fakes: prepare() fetches the latest release and plans; apply() downloads, verifies and writes.

const REPO = "yonatankarp/lorekeeper-obsidian";
const INSTALLED = "_lorekeeper/installed.json";
const BASELINE = "_lorekeeper/baselines/v0.1.0.json";

async function readJson(adapter, path) {
  return (await adapter.exists(path)) ? JSON.parse(await adapter.read(path)) : null;
}

async function get(request, url) {
  const res = await request({ url, throw: false });
  if (res.status < 200 || res.status >= 300) throw new Error(`Couldn't download ${url} (${res.status}).`);
  return res;
}

async function hashes(adapter, subtle, update, paths) {
  const out = {};
  for (const p of paths) if (await adapter.exists(p)) out[p] = await update.sha256Hex(await adapter.read(p), subtle);
  return out;
}

async function prepare({ adapter, request, subtle, update }) {
  const tag = (await get(request, `https://api.github.com/repos/${REPO}/releases/latest`)).json.tag_name;
  const release = (await get(request, update.rawUrl(REPO, tag, "lorekeeper.json"))).json;
  const installed = (await readJson(adapter, INSTALLED)) ?? (await readJson(adapter, BASELINE));
  if (installed?.version === release.version) return { latest: true, version: release.version };
  const paths = [...new Set([...Object.keys(release.files), ...Object.keys(installed?.files ?? {})])];
  const current = await hashes(adapter, subtle, update, paths);
  return { tag, release, installed, plan: update.planUpdate({ installed, current, release }) };
}

async function ensureFolder(adapter, path) {
  const dir = path.split("/").slice(0, -1).join("/");
  if (dir && !(await adapter.exists(dir))) await adapter.mkdir(dir);
}

async function apply({ adapter, request, subtle, update, tag, release, installed, plan }) {
  const written = [];
  const failed = [];
  for (const p of [...plan.add, ...plan.replace]) {
    try {
      const text = (await get(request, update.rawUrl(REPO, tag, p))).text;
      if ((await update.sha256Hex(text, subtle)) !== release.files[p].sha256) throw new Error("hash mismatch");
      await ensureFolder(adapter, p);
      await adapter.write(p, text);
      written.push(p);
    } catch {
      failed.push(p);
    }
  }
  for (const p of plan.remove) {
    await adapter.remove(p);
    written.push(p);
  }
  for (const p of plan.merge) {
    try {
      const theirs = (await get(request, update.rawUrl(REPO, tag, p))).text;
      const mine = (await adapter.exists(p)) ? JSON.parse(await adapter.read(p)) : null;
      const merged = !mine ? JSON.parse(theirs)
        : p.endsWith("community-plugins.json") ? update.mergeEnabledPlugins(mine, installed?.plugins ?? [], release.plugins)
        : update.mergeQuickAdd(mine, JSON.parse(theirs));
      await ensureFolder(adapter, p);
      await adapter.write(p, JSON.stringify(merged, null, 2) + "\n");
      written.push(p);
    } catch {
      failed.push(p);
    }
  }
  if (!failed.length) {
    const files = await hashes(adapter, subtle, update, Object.keys(release.files));
    await adapter.write(INSTALLED, JSON.stringify({ version: release.version, plugins: release.plugins, files }, null, 2) + "\n");
  }
  const reload = written.some((p) => p.startsWith(".obsidian/plugins/") || p.startsWith(".obsidian/themes/"));
  return { written, failed, reload };
}

module.exports = { REPO, prepare, apply };
```

```js
// QuickAdd: Update Lorekeeper. Shows what the latest release would change, asks, then updates (lib/updater.js).
module.exports = async ({ app, quickAddApi, obsidian }) => {
  const m = { exports: {} };
  new Function("module", await app.vault.adapter.read("_lorekeeper/lib/load.js"))(m);
  const lk = await m.exports(app);
  const ctx = { adapter: app.vault.adapter, request: obsidian.requestUrl, subtle: crypto.subtle, update: lk.update };
  let prepared;
  try {
    prepared = await lk.updater.prepare(ctx);
  } catch (e) {
    return new obsidian.Notice(`Couldn't check for updates: ${e.message}`);
  }
  if (prepared.latest) return new obsidian.Notice(`Lorekeeper is up to date (v${prepared.version}).`);
  const { plan, release } = prepared;
  const lines = [
    `${plan.add.length} new, ${plan.replace.length} updated, ${plan.remove.length} removed, ${plan.merge.length} merged.`,
    plan.kept.length ? `Kept because you edited them: ${plan.kept.join(", ")}.` : "",
  ].filter(Boolean).join("\n");
  const go = await quickAddApi.yesNoPrompt(`Update to v${release.version}?`, lines).catch(() => false);
  if (!go) return;
  const out = await lk.updater.apply({ ...ctx, ...prepared });
  if (out.failed.length) return new obsidian.Notice(`Some files didn't update: ${out.failed.join(", ")}. Run Update Lorekeeper again.`, 0);
  new obsidian.Notice(`Updated to v${release.version}.`);
  if (out.reload && (await quickAddApi.yesNoPrompt("Reload Obsidian?", "Plugins or the theme changed. Reload to use them.").catch(() => false)))
    app.commands.executeCommandById("app:reload");
};
```

```js
// Backups with Obsidian Git: is this vault ready, and is it about to push a campaign to the public template?

function originUrl(gitConfig) {
  let inOrigin = false;
  for (const line of gitConfig.split(/\r?\n/)) {
    const section = line.match(/^\s*\[(.+)\]\s*$/);
    if (section) inOrigin = section[1].trim() === 'remote "origin"';
    else if (inOrigin) {
      const url = line.match(/^\s*url\s*=\s*(.+?)\s*$/);
      if (url) return url[1];
    }
  }
  return "";
}

const isTemplateRepo = (url) => /github\.com[:/]yonatankarp\/lorekeeper-obsidian(\.git)?\/?$/.test(url);

function backupStatus(gitConfig, pluginOn) {
  if (gitConfig === null) return { level: "warn", message: "No backup yet: this vault isn't a git repository. See docs/BACKUP.md." };
  const url = originUrl(gitConfig);
  if (!url) return { level: "warn", message: "This vault has no origin repository to back up to. See docs/BACKUP.md, step 2." };
  if (isTemplateRepo(url))
    return { level: "warn", message: "This vault still points at the public Lorekeeper template. Point it at your own private repository before turning on Obsidian Git (docs/BACKUP.md, step 2)." };
  if (!pluginOn) return { level: "warn", message: `Ready to back up to ${url}: turn on Obsidian Git in Settings > Community plugins.` };
  return { level: "ok", message: `Backing up to ${url}.` };
}

module.exports = { originUrl, isTemplateRepo, backupStatus };
```

```js
// D&D Beyond: links, character-service replies and portraits, ported from Lorekeeper's src-tauri/src/dndbeyond.rs
// (32a07f6). Network calls are passed in (getJson, getText) so lookup() is testable.

const SITE = "https://www.dndbeyond.com";
const MAX_CHARACTERS = 30;
const MESSAGES = {
  expired: "Your D&D Beyond sign-in expired. Run Sign in to D&D Beyond again.",
  notShared: "D&D Beyond won't share this character. Run Sign in to D&D Beyond, or set the character to Public.",
  signInForCampaign: "Run Sign in to D&D Beyond to import from a campaign.",
  badLink: "That isn't a link to a D&D Beyond character or campaign.",
  invite: "That's a campaign invite. Paste the campaign's own page link (dndbeyond.com/campaigns/<number>).",
};
const ALIGNMENTS = ["Lawful Good", "Neutral Good", "Chaotic Good", "Lawful Neutral", "Neutral", "Chaotic Neutral", "Lawful Evil", "Neutral Evil", "Chaotic Evil"];

const sheetUrl = (id) => `${SITE}/characters/${id}`;
const sheetId = (url) => String(url ?? "").match(/^https:\/\/(?:www\.)?dndbeyond\.com\/(?:[^?#]*\/)?characters\/(\d+)/)?.[1] ?? "";
const number = (s) => (/^\d{1,15}$/.test(s) ? Number(s) : null);
const text = (v) => (typeof v === "string" ? v.trim() : "");

function parseLink(link) {
  const trimmed = String(link).trim();
  const bare = number(trimmed);
  if (bare !== null) return { character: bare };
  let url;
  try {
    url = new URL(trimmed.includes("://") ? trimmed : `https://${trimmed}`);
  } catch {
    throw new Error(MESSAGES.badLink);
  }
  if (!["https:", "http:"].includes(url.protocol) || !["www.dndbeyond.com", "dndbeyond.com"].includes(url.hostname)) throw new Error(MESSAGES.badLink);
  const parts = url.pathname.split("/").filter(Boolean);
  let found = null;
  if (parts[0] === "characters") found = number(parts[1] ?? "") !== null && { character: number(parts[1]) };
  else if (parts[0] === "profile" && parts[2] === "characters") found = number(parts[3] ?? "") !== null && { character: number(parts[3]) };
  else if (parts[0] === "campaigns" && parts[1] === "join") throw new Error(MESSAGES.invite);
  else if (parts[0] === "campaigns") found = number(parts[1] ?? "") !== null && { campaign: number(parts[1]) };
  if (!found) throw new Error(MESSAGES.badLink);
  return found;
}

function characterIds(html) {
  const ids = [];
  for (const m of html.matchAll(/\/characters\/(\d+)/g)) {
    const id = number(m[1]);
    if (id !== null && !ids.includes(id)) ids.push(id);
  }
  return ids;
}

function party(v) {
  const members = v?.data?.campaign?.characters;
  return Array.isArray(members)
    ? members.filter((m) => Number.isInteger(m?.characterId)).map((m) => [m.characterId, text(m.characterName), text(m.username)])
    : [];
}

function appearance(d) {
  const looks = [["Gender", "gender"], ["Age", "age"], ["Height", "height"], ["Weight", "weight"], ["Eyes", "eyes"], ["Hair", "hair"], ["Skin", "skin"]]
    .map(([label, key]) => {
      const v = typeof d[key] === "number" ? String(d[key]) : text(d[key]);
      return v ? `${label} ${v}` : "";
    })
    .filter(Boolean);
  return [looks.join(" · "), text(d.traits?.appearance)].filter(Boolean).join("\n\n");
}

function personality(traits) {
  return [["Traits", "personalityTraits"], ["Ideals", "ideals"], ["Bonds", "bonds"], ["Flaws", "flaws"]]
    .map(([label, key]) => {
      const lines = text(traits?.[key]).split("\n").map((l) => l.trim()).filter(Boolean);
      if (!lines.length) return "";
      return lines.length === 1 ? `**${label}:** ${lines[0]}` : `**${label}:**\n${lines.map((l) => `- ${l}`).join("\n")}`;
    })
    .filter(Boolean)
    .join("\n\n");
}

function portraitUrl(url) {
  try {
    const u = new URL(url);
    return u.protocol === "https:" && (u.hostname === "dndbeyond.com" || u.hostname.endsWith(".dndbeyond.com"));
  } catch {
    return false;
  }
}

function imageExt(b) {
  if (b[0] === 0xff && b[1] === 0xd8 && b[2] === 0xff) return "jpg";
  if (b[0] === 0x89 && b[1] === 0x50 && b[2] === 0x4e && b[3] === 0x47) return "png";
  if (b[0] === 0x47 && b[1] === 0x49 && b[2] === 0x46 && b[3] === 0x38) return "gif";
  const ascii = (from, to) => String.fromCharCode(...b.slice(from, to));
  if (ascii(0, 4) === "RIFF" && ascii(8, 12) === "WEBP") return "webp";
  return null;
}

function parseCharacter(id, v) {
  const d = v?.data && typeof v.data === "object" ? v.data : {};
  const race = text(d.race?.fullName) || text(d.race?.baseName);
  const classes = (Array.isArray(d.classes) ? d.classes : [])
    .map((c) => [text(c?.definition?.name), Number.isInteger(c?.level) ? c.level : 0, text(c?.subclassDefinition?.name)])
    .filter(([name]) => name);
  const sub = (s) => (s ? ` (${s})` : "");
  const names = classes.length === 1 ? `${classes[0][0]}${sub(classes[0][2])}` : classes.map(([n, l, s]) => `${n} ${l}${sub(s)}`).join(" / ");
  const own = party(v).find((m) => m[0] === id)?.[2] ?? "";
  const avatar = text(d.decorations?.avatarUrl);
  return {
    id, name: text(d.name), race, classes: names, level: classes.reduce((sum, c) => sum + c[1], 0),
    player: text(d.username) || own, url: sheetUrl(id),
    background: text(d.background?.definition?.name) || text(d.background?.customBackground?.name),
    alignment: Number.isInteger(d.alignmentId) ? ALIGNMENTS[d.alignmentId - 1] ?? "" : "",
    appearance: appearance(d), personality: personality(d.traits), portrait: portraitUrl(avatar) ? avatar : "", error: "",
  };
}

function tokenFrom(status, json) {
  const token = json?.token;
  if (status >= 200 && status < 300 && typeof token === "string" && token) return token;
  if (status === 401 || status === 403 || (status >= 200 && status < 300)) throw new Error(MESSAGES.expired);
  throw new Error(`D&D Beyond's sign-in service said: ${status}`);
}

function characterError(status, json, id) {
  if (status === 401 || status === 403) return MESSAGES.notShared;
  if (status === 404) return `D&D Beyond has no character ${id}.`;
  return `D&D Beyond said: ${json?.message ?? "unexpected reply"} (${status})`;
}

async function lookup(link, { getJson, getText, token, cookie }) {
  const target = parseLink(link);
  let queue;
  if (target.character !== undefined) queue = [[target.character, "", ""]];
  else {
    if (!token) throw new Error(MESSAGES.signInForCampaign);
    const page = await getText(`${SITE}/campaigns/${target.campaign}`, { Cookie: `CobaltSession=${cookie}` });
    const ids = page.status >= 200 && page.status < 300 ? characterIds(page.text) : [];
    if (!ids.length) throw new Error("D&D Beyond didn't show that campaign's characters. Paste a link to a character in it instead: its party comes along.");
    queue = ids.map((id) => [id, "", ""]);
  }
  const headers = token ? { Authorization: `Bearer ${token}` } : {};
  const found = [];
  for (let next = 0; next < queue.length && found.length < MAX_CHARACTERS; next++) {
    const [id, name, user] = queue[next];
    const res = await getJson(`https://character-service.dndbeyond.com/character/v5/character/${id}`, headers);
    if (res.status >= 200 && res.status < 300 && res.json?.data && typeof res.json.data === "object") {
      for (const member of party(res.json)) if (!queue.some((q) => q[0] === member[0])) queue.push(member);
      const c = parseCharacter(id, res.json);
      found.push({ ...c, player: c.player || user });
    } else {
      found.push({ id, name: name || `Character ${id}`, race: "", classes: "", level: 0, player: user, url: sheetUrl(id),
        background: "", alignment: "", appearance: "", personality: "", portrait: "", error: characterError(res.status, res.json, id) });
    }
  }
  return found;
}

module.exports = { MESSAGES, MAX_CHARACTERS, ALIGNMENTS, sheetUrl, sheetId, parseLink, characterIds, party, parseCharacter, portraitUrl, imageExt, tokenFrom, characterError, lookup };
```

```js
// PC pages kept up to date with D&D Beyond, ported from Lorekeeper's src/vault.js (32a07f6, lines 496-554).

const sheetId = (url) => String(url ?? "").match(/^https:\/\/(?:www\.)?dndbeyond\.com\/(?:[^?#]*\/)?characters\/(\d+)/)?.[1] ?? "";
const baseName = (path) => path.split("/").pop().replace(/\.md$/i, "");

function pcPageFor(character, notes) {
  const pcs = notes.filter((n) => n.path.startsWith("PCs/"));
  const id = String(character.id);
  const named = (n) => baseName(n.path).toLowerCase() === character.name.trim().toLowerCase() && [id, ""].includes(sheetId(n.dndbeyond));
  return (pcs.find((n) => sheetId(n.dndbeyond) === id) ?? pcs.find(named))?.path ?? null;
}

function safePageName(name, fallback) {
  const clean = name.replace(/[\\/:*?"<>|#^[\]]/g, " ").replace(/\s+/g, " ").trim().replace(/^\.+\s*/, "");
  return !clean || clean.endsWith(".") ? fallback : clean;
}

function fillSection(md, heading, text) {
  if (!text) return md;
  const nl = md.includes("\r\n") ? "\r\n" : "\n";
  const lines = md.split(nl);
  const block = ["", ...text.split("\n"), ""];
  const at = lines.findIndex((l) => l.trim().toLowerCase() === `## ${heading}`.toLowerCase());
  if (at === -1) {
    const notes = lines.findIndex((l) => /^##\s+notes\s*$/i.test(l));
    if (notes === -1) return `${md.replace(/\s*$/, "")}${nl}${nl}## ${heading}${nl}${block.join(nl)}`;
    lines.splice(notes, 0, `## ${heading}`, ...block);
    return lines.join(nl);
  }
  let end = at + 1;
  while (end < lines.length && !/^#{1,2}\s/.test(lines[end])) end++;
  if (lines.slice(at + 1, end).some((l) => l.trim())) return md;
  lines.splice(at + 1, end - at - 1, ...block);
  return lines.join(nl);
}

const blank = (v) => v === undefined || v === null || String(v).trim() === "";

function applyCharacter(fm, c, portraitLink = "") {
  const replace = { race: c.race, class: c.classes, level: c.level || "", background: c.background, alignment: c.alignment, dndbeyond: c.url };
  for (const [k, v] of Object.entries(replace)) if (!blank(v)) fm[k] = v;
  if (!blank(c.player) && blank(fm.player)) fm.player = c.player;
  if (!blank(portraitLink) && blank(fm.portrait)) fm.portrait = portraitLink;
  return fm;
}

module.exports = { pcPageFor, safePageName, fillSection, applyCharacter };
```

```js
// D&D Beyond sign-in: the pasted CobaltSession cookie, kept only in Obsidian's secret storage (never in a vault file,
// so backups never carry it).

const SECRET_ID = "lorekeeper-dndbeyond";

const cleanCookie = (input) => String(input ?? "").trim().replace(/^CobaltSession=/i, "").replace(/^"|"$/g, "").trim();

function signIn(secretStorage, input) {
  if (!secretStorage?.setSecret) throw new Error("Signing in needs Obsidian's secret storage (Obsidian 1.13 or later).");
  const cookie = cleanCookie(input);
  if (!cookie) throw new Error("Paste your CobaltSession cookie to sign in (see docs/DNDBEYOND.md).");
  secretStorage.setSecret(SECRET_ID, cookie);
}

function signOut(secretStorage) {
  secretStorage?.setSecret?.(SECRET_ID, "");
}

module.exports = { SECRET_ID, cleanCookie, signIn, signOut };
```

```markdown
# Characters from D&D Beyond

**Import from D&D Beyond** (command palette, `⌘P` or `Ctrl+P`): paste a character link (`dndbeyond.com/characters/…`) or its number. The character's party comes along. Untick any you don't want, and each one updates its page in `PCs/` (the one linking to its sheet, else the one with its name) or gets a new page from the PC template.

**Refresh from D&D Beyond** on an open PC page reads the character again, say after a level up.

What D&D Beyond updates: `race`, `class` (with subclass), `level`, `background`, `alignment` and the `dndbeyond` sheet link. `player` and the `portrait` (saved into `Attachments/`) are only filled in when empty. **Appearance** and **Personality** are written only while those sections are empty. Public characters work without signing in. "Campaign Only" characters and campaign links need you signed in.

## Signing in

D&D Beyond doesn't let other apps sign you in, so you copy your sign-in cookie from your browser once. It's your D&D Beyond session: treat it like a password and don't share it. Lorekeeper keeps it in Obsidian's secret storage, never in a file in your vault, so backups never include it.

1. Sign in at dndbeyond.com in your browser.
2. Open the developer tools: **Chrome** `⌥⌘I` / `Ctrl+Shift+I`, then **Application > Cookies > https://www.dndbeyond.com**. **Firefox** `⌥⌘I` / `Ctrl+Shift+I`, then **Storage > Cookies**. **Safari**: turn on **Settings > Advanced > Show features for web developers**, then `⌥⌘I` and **Storage > Cookies**.
3. Copy the value of **CobaltSession**.
4. In Obsidian, run **Sign in to D&D Beyond** and paste it.

When it expires, imports say **Your D&D Beyond sign-in expired**: sign in again the same way. **Sign out of D&D Beyond** removes it.
```
