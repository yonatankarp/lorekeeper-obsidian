## Note symbols

Start a note with a symbol to file it. It works in the note box and on any line under **Notes** in a session.

| Symbol | Goes to |
|---|---|
| `@` | NPCs |
| `#` | Loot |
| `!` | Quests |
| `?` | Mysteries |
| `"` | Quotes |
| none | What happened |

## Commands

Open the command palette with `⌘P` or `Ctrl+P` and type the name (it shows as "QuickAdd: ...").

| Command | What it does |
|---|---|
| **Update Lorekeeper** | Shows what changes, asks, then updates the template |
| **Check backup** | Says whether the vault is ready to back up |
| **Import from D&D Beyond** | Fills PC pages from a character link |
| **Refresh from D&D Beyond** | Re-reads the open PC page's character |
| **Sign in to D&D Beyond** | Saves your sign-in cookie, for Campaign Only characters |
| **Sign out of D&D Beyond** | Removes it |
| **Pick your character** | Says who you play on this device: a PC, the DM or solo |
| **Make line private** (`⌘⇧P` / `Ctrl+Shift+P`) | Moves the current line, or the selected lines, to your private notes |
| **Make private** | Moves the open page to your private folder |
| **Make shared** | Moves one of your private pages back for the party |

## Playing with your party

Run **Pick your character** first, on each device. Start a note with `~` in the note box to keep it private. In the editor, use **Make line private**: a `~` line typed in Quick note stays put until you do. If ⌘⇧P (Ctrl+Shift+P) does nothing after updating, set **Make line private** in **Settings > Hotkeys**. See docs/PARTY.md.

## Links and images

- `[[Mirela]]` links a page. `@[[Mirela]]` files the note under NPCs and links her.
- `![[map.png]]` shows an image from `Attachments/`. Add `|300` for a width: `![[map.png|300]]`.
- Paste or drop an image into a page to save it in `Attachments/`.

## Anywhere

After setting up the hotkeys in docs/CAPTURE.md:

| Shortcut | What it does |
|---|---|
| `⌘⌥N` / `Ctrl+Alt+N` | Note box over any app. On macOS, with Obsidian in front, it opens Quick note instead |
| `⌘⇧S` / `Ctrl+Shift+S` | Saves the selected text, or the clipboard |

## In Obsidian

| Shortcut | What it does |
|---|---|
| `⌘⌥N` / `Ctrl+Alt+N` | Quick note: a new line in the current session, with link suggestions |
| `⌘J` / `Ctrl+J` | Current session |
| `⌘N` / `Ctrl+N` | New page: NPC, PC, Location, Item, Faction, Quest, Lore or your own |
| `⌘K` / `Ctrl+K` | Search |
| `⌘O` / `Ctrl+O` | Open a page by name |
| `⌘G` / `Ctrl+G` | Connections (the graph) |
| `⌘/` / `Ctrl+/` | This cheat sheet |
| `⌘E` / `Ctrl+E` | Switch between editing and reading |
| `F2` | Rename the page: links to it follow |
